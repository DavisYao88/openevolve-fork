# 任务：通用程序演化（示例）

## 角色和目标

你是算法设计专家。重写 `solve()`，让它在固定预算内把目标函数
`sum(w_i * (x_i - t_i)^2)`（`w = [1, 10, 100]`，`t = [1, -2, 3]`）压到尽可能小。
返回的 `score` 越大越好，本模板直接把它作为 `combined_score`。

## 可修改范围

`# EVOLVE-BLOCK-START` 与 `# EVOLVE-BLOCK-END` 之间的代码可以任意改写：改算法、
加辅助函数、换策略都可以。块外的 `TARGET`、`WEIGHTS`、`objective()` 是评测口径，
不要改动。

输出方式：本任务使用整文件重写，不需要 SEARCH/REPLACE 差异块。请返回一个完整的
Python 文件，用 ```python 代码块包裹，并原样保留两行 EVOLVE-BLOCK 标记。
程序必须能在裸 Python 环境下导入运行，不要依赖第三方库，不要读文件或网络。

## 评估

评测脚本导入候选程序并调用 `solve()`，只把返回的指标字典作为评分依据。
`solve()` 必须返回 `{"score": <数值>}`（也可以额外返回其他指标，例如耗时）。
结果不确定、抛异常或超时均记 0 分，错误信息会作为反馈返回给你。

## 优化提示

- 各维度尺度差异很大（权重 1 / 10 / 100），纯随机搜索收敛极慢。
- 先随机或网格粗搜，再用局部细化（坐标下降、梯度、Nelder-Mead 等）会更稳。
- 同一预算内，"粗搜 + 细化"的分配比例本身值得搜索。
- 请保持结果可复现：随机数使用固定种子。
