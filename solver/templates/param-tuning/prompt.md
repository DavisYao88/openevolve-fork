# 任务：通用参数调优（示例）

## 角色和目标

你是优化算法调参专家。给定固定的评测流程，只调整 `init.py` 中 `PARAMS` 的取值，
让返回的 `loss` 尽可能小（分数 `-log(loss) × 100` 尽可能大）。

## 可修改范围

唯一可修改的是 `init.py` 中 `PARAMS` 字典现有键对应的值。输出完整 Python 文件，
并保持 docstring、字典键、键顺序原样。不要新增或删除键，不要添加 import、
函数、类、I/O 或其他可执行语句。

输出方式：本任务使用整文件重写，不需要 SEARCH/REPLACE 差异块。请返回一个完整的
Python 文件，用 ```python 代码块包裹，并原样保留 `# EVOLVE-BLOCK-START` 与
`# EVOLVE-BLOCK-END` 两行标记；块外改动会被丢弃。

## 训练和评估

评测流程固定：评测脚本读取候选参数，跑固定的优化过程，只向标准输出打印一个
JSON 对象。不得在候选程序里模拟评测或伪造指标。

评分：`score = -log(loss) × 100`，越大越好。参数越界、结构违规、评测失败或超时
均记 0 分，并把错误原因作为反馈返回给你。

## 调参提示

- `step_size` 是本问题最敏感的参数：问题条件数为 100，步长过大直接发散（记 0 分），
  过小则 300 步内收敛不足。有效步长约为 `step_size / (1 - momentum)`。
- `momentum` 能加速沿病态方向的收敛，但接近 1 时容易与过大的步长一起发散。
- `restarts` 是线性成本，只在前面两者调好之后再小幅增加。
- 每次优先改动 1–3 个参数，小于 1 分的变化视为噪声，不要追逐。
