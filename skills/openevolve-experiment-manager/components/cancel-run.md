# 组件 — 取消任务

**输入**：`run_id`
**输出**：终止状态

---

## 1. 终止运行中的任务

```bash
curl -s -X POST "http://127.0.0.1:8080/api/runs/<id>/cancel"
```

成功返回 `200`，body 为 `{run: {...}}`，任务状态变为 `interrupted`。

## 2. 错误处理

| 返回码 | 含义 |
|--------|------|
| 404 | 找不到该任务 |
| 409 | 任务不是由本服务启动，或已结束 |
| 500 | 无法终止（进程组 kill 失败） |

## 3. 说明

- 取消只终止「本服务启动且仍在跑」的任务；历史任务或外部启动的任务会 409。
- 取消后 `/api/runs/<id>/progress` 的 `status` 会变为 `interrupted`。
